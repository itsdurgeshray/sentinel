# Sentinel Conservation Consulting

Static website. No build step.

- `/` — the main site (`index.html`, `css/`, `js/`, `img/`).
- `/experience` — the 3D scrollytelling version. It is not linked from the main site and is marked `noindex`.

Serve the folder with any static host (GitHub Pages, Netlify, Vercel), or locally:

```bash
python3 -m http.server 8000
```

The contact address `hello@sentinel-consulting.com` is a placeholder until the real one is confirmed.
